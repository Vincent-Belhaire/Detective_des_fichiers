# Séance 5 TICE 6e — Détective des fichiers

Mini-site autonome en HTML, CSS et JavaScript. Aucune bibliothèque ni connexion Internet n’est nécessaire après téléchargement.

## Contenu

- `index.html` : structure de la séance et contenus pédagogiques
- `style.css` : charte graphique et mise en page responsive
- `script.js` : interactions, score, progression, aides et bilan

## Tester sur un ordinateur

Ouvrir simplement `index.html` dans un navigateur récent (Firefox, Chrome ou Edge).

## Publier avec GitHub Pages

1. Créer un nouveau dépôt GitHub.
2. Déposer les trois fichiers `index.html`, `style.css` et `script.js` à la racine du dépôt.
3. Dans le dépôt, ouvrir **Settings**, puis **Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main`, le dossier `/ (root)`, puis enregistrer.
6. Attendre une à deux minutes : l’adresse publique s’affiche dans la section GitHub Pages.

Tous les fichiers et noms utilisés dans les activités sont fictifs. Le site ne collecte ni ne transmet aucune donnée.
